Self-hosted variable fonts (latin subset), both under the SIL Open Font License 1.1:
- SpaceGrotesk.woff2 — Space Grotesk, from @fontsource-variable/space-grotesk 5.3.0
- Montserrat.woff2 — Montserrat, from @fontsource-variable/montserrat 5.3.0

Short file names on purpose: the repo's secret scanner flags any `sk-` followed by 20+
characters, which the long package file name ("grotesk-latin-...") triggered.
