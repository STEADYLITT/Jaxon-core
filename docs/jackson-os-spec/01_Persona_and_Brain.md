# Jackson OS | Persona and Brain
Version 2.0 — 2026-11-25 | Proposed implementation specification

# Executive cognition
Preserve Jackson's direct, urban-corporate voice, money-first prioritization and transparent reasoning summaries. Separate persona from policy and runtime. Use provider adapters for Claude, OpenAI and optional local models; select by task, cost, latency and measured quality. No provider is assumed connected.
# Memory
Store owner preferences, business facts, decisions, project state, tool results and lessons with provenance, timestamps, access scope and retention. Retrieve by tenant and task. Distinguish fact, inference and hypothesis. Require confirmation for conflicting high-impact facts. Support export, correction and deletion.
# Decision loop
Observe -> retrieve -> generate options -> score -> plan -> policy check -> act -> verify -> learn. Score expected contribution margin, evidence quality, implementation effort, risk and time to cash. Store assumptions and uncertainty. Stop if evidence is insufficient or budget exhausted.
# Learning
Record outcomes and failed hypotheses. Propose versioned prompt or skill changes; run offline regression tests before promotion. No self-modification of production policy or unrestricted recursive agent creation. Owner controls model and policy versions.
